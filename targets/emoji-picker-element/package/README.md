# @effectified/emoji-picker-element

> a web component bound from its manifest

[emoji-picker-element](https://www.npmjs.com/package/emoji-picker-element) for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types, and tested against the real library. Docs, examples and the agent skill: https://effectified.dev/emoji-picker-element

## Install

```sh
pnpm add https://effectified.dev/emoji-picker-element.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
npm install --allow-remote=all https://effectified.dev/emoji-picker-element.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
bun add https://effectified.dev/emoji-picker-element.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

`https://effectified.dev/emoji-picker-element.tgz` always installs the newest release. This one is 1.29.1+3, for emoji-picker-element 1.29.1; to pin it, install https://github.com/effectified/packages/releases/download/emoji-picker-element-v1.29.1+3/effectified-emoji-picker-element-1.29.1+3.tgz. Effect UI is in public preview: install its snapshot build, as above.
