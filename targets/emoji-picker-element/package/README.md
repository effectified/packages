# @effectified/emoji-picker-element

[emoji-picker-element](https://www.npmjs.com/package/emoji-picker-element) 1.29.1 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- 1 elements bound with `Html.customElement`: each property and event typed by emoji-picker-element's own declarations, each event's `detail` a message.
- Importing a binding (`@effectified/emoji-picker-element/elements/EmojiPicker`) defines its element; `@effectified/emoji-picker-element` defines them all.

```ts
import { EmojiPicker } from "@effectified/emoji-picker-element";

// in a view: EmojiPicker(h).customCategorySorting(...).on("emoji-click", (detail) => Message.Changed({ ... }))
```

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/engine/releases/download/emoji-picker-element-v1.29.1/effectified-emoji-picker-element-1.29.1.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
