# @effectified/sharp

> a builder that is also a Node stream

[sharp](https://www.npmjs.com/package/sharp) in [Effect](https://effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types, and tested against the real library. Docs, examples and the agent skill: https://effectified.dev/sharp

## Install

```sh
pnpm add https://effectified.dev/sharp.tgz effect
npm install --allow-remote=all https://effectified.dev/sharp.tgz effect
bun add https://effectified.dev/sharp.tgz effect
```

`https://effectified.dev/sharp.tgz` always installs the newest release. This one is 0.35.5+5, for sharp 0.35.5; to pin it, install https://github.com/effectified/packages/releases/download/sharp-v0.35.5+5/effectified-sharp-0.35.5+5.tgz.

## Examples

Each is code from a test that passes in CI.

### Resize an image and read its metadata

```ts
import { sharp } from "@effectified/sharp";

const red = { create: { width: 4, height: 2, channels: 3, background: "#ff0000" } } as const;

const image = yield* sharp(red);
// The builder chain stays synchronous; toBuffer runs it, as an Effect.
const png = yield* image.resize(2, 1).png().toBuffer();
const metadata = yield* (yield* sharp(png)).metadata();
```

From `test/facade.test.ts`.

## API

Exports: `sharp`.

| Error | From | Reasons |
|---|---|---|
| `SharpError` | any other failure | `ERR_DLOPEN_DISABLED` |

| Handle | Effects | Of an `Option` | Streams | Events | Released by |
|---|---|---|---|---|---|
| `Sharp` | `metadata`, `stats`, `toBuffer`, `toFile`, `toUint8Array` | – | – | – | – |
