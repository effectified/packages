# @effectified/sharp

[sharp](https://www.npmjs.com/package/sharp) 0.35.5 in [Effect](https://effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types and `recipe.json`.

- Async calls are `Effect`s, async iterables are `Stream`s, and failures are tagged errors:
  `SharpError`.
- Handles it wraps: `Sharp`.
- `Upstream` re-exports sharp itself, and every facade keeps its upstream object as `.upstream`.

Offered: `default`. Types: bundled with the package.
