# @effectified/fluentui-web-components

[@fluentui/web-components](https://www.npmjs.com/package/@fluentui/web-components) 3.2.5 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- 40 elements bound with `Html.customElement`: each property and event typed by @fluentui/web-components's own declarations, each event's `detail` a message.
- Importing a binding (`@effectified/fluentui-web-components/elements/Accordion`) defines its element; `@effectified/fluentui-web-components` defines them all.
- Mounts: `DialogOpen`: an instance per element, updated from the view's args, released with the element.

```ts
import { Accordion } from "@effectified/fluentui-web-components";

// in a view: Accordion(h).expandmode(...).on("change", (detail) => Message.Changed({ ... }))
```

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/engine/releases/download/fluentui-web-components-v3.2.5/effectified-fluentui-web-components-3.2.5.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
