# @effectified/chart.js

> a chart updated in place, clicks as messages

[chart.js](https://www.npmjs.com/package/chart.js) for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types, and tested against the real library. Docs, examples and the agent skill: https://effectified.dev/chart.js

## Install

```sh
pnpm add https://effectified.dev/chart.js.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
npm install --allow-remote=all https://effectified.dev/chart.js.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
bun add https://effectified.dev/chart.js.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

`https://effectified.dev/chart.js.tgz` always installs the newest release. This one is 4.6.2+3, for chart.js 4.6.2; to pin it, install https://github.com/effectified/packages/releases/download/chart.js-v4.6.2+3/effectified-chart.js-4.6.2+3.tgz. Effect UI is in public preview: install its snapshot build, as above.

## Examples

Each is code from a test that passes in CI.

### A chart drawn from the Model, clicks as messages

```ts
import { Mount, UiSchema } from "@effect/ui";
import { BrowserHost, Html } from "@effect/ui/html";
import { Effect, Layer, Schema } from "effect";
import { ChartMount } from "@effectified/chart.js";

const Message = UiSchema.TaggedEnum({
	ClickedAdd: {},
	ClickedBar: { index: Schema.Number },
	ClickedHide: {},
});

const Bars = Html.component({
	name: "Bars",
	model: Schema.Struct({ values: Schema.Array(Schema.Number), clicked: Schema.Number, shown: Schema.Boolean }),
	message: Message,
}).make({
	init: () => ({ values: [3, 1, 2], clicked: -1, shown: true }),
	update: {
		ClickedAdd: ($) => $.evolve({ values: (values) => [...values, values.length + 1] }),
		ClickedBar: ($, { index }) => $.evolve({ clicked: () => index }),
		ClickedHide: ($) => $.evolve({ shown: () => false }),
	},
	view: (h, model) =>
		h.div.children(
			h.button.id("add").on("click", Message.ClickedAdd()).children("Add"),
			h.button.id("hide").on("click", Message.ClickedHide()).children("Hide"),
			h.output.id("state").children(JSON.stringify(model)),
			model.shown
				? h.div.style({ width: "400px", height: "200px" }).children(
						h.canvas.id("chart").onMount(
							ChartMount({
								config: {
									type: "bar",
									data: { labels: model.values.map((_, index) => `#${index}`), datasets: [{ label: "values", data: [...model.values] }] },
									options: { animation: false, responsive: true, maintainAspectRatio: false },
								},
							}).pipe(Mount.map(({ index }) => Message.ClickedBar({ index }))),
						),
					)
				: h.p.id("hidden").children("hidden"),
		),
});

Layer.launch(BrowserHost.mount(Bars, {}, document.getElementById("root")!)).pipe(Effect.runFork);
```

From `test/fixtures/chart.ts`.
