# @effectified/codemirror-view

[@codemirror/view](https://www.npmjs.com/package/@codemirror/view) 6.44.0 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- Mounts: `Editor`: an instance per element, updated from the view's args, released with the element.

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/engine/releases/download/codemirror-view-v6.44.0/effectified-codemirror-view-6.44.0.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
