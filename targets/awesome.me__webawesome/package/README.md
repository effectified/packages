# @effectified/webawesome

[@awesome.me/webawesome](https://www.npmjs.com/package/@awesome.me/webawesome) 3.15.0 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- 78 elements bound with `Html.customElement`: each property and event typed by @awesome.me/webawesome's own declarations, each event's `detail` a message.
- Importing a binding (`@effectified/webawesome/elements/Accordion`) defines its element; `@effectified/webawesome` defines them all.

```ts
import { Accordion } from "@effectified/webawesome";

// in a view: Accordion(h).appearance(...).on("wa-after-collapse", (detail) => Message.Changed({ ... }))
```

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/engine/releases/download/webawesome-v3.15.0/effectified-webawesome-3.15.0.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
