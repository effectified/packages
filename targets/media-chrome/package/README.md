# @effectified/media-chrome

[media-chrome](https://www.npmjs.com/package/media-chrome) 4.19.5 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- 47 elements bound with `Html.customElement`: each property and event typed by media-chrome's own declarations, each event's `detail` a message.
- Importing a binding (`@effectified/media-chrome/elements/AirplayButton`) defines its element; `@effectified/media-chrome` defines them all.

```ts
import { AirplayButton } from "@effectified/media-chrome";

// in a view: AirplayButton(h).disabled(...).on("mediaairplayrequest", (detail) => Message.Changed({ ... }))
```

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/packages/releases/download/media-chrome-v4.19.5/effectified-media-chrome-4.19.5.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
