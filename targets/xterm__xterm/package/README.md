# @effectified/xterm

[@xterm/xterm](https://www.npmjs.com/package/@xterm/xterm) 6.0.0 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- Mounts: `Terminal`: an instance per element, updated from the view's args, released with the element.

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/engine/releases/download/xterm-v6.0.0/effectified-xterm-6.0.0.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
