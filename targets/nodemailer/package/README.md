# @effectified/nodemailer

[nodemailer](https://www.npmjs.com/package/nodemailer) 10.6.1 in [Effect](https://effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types and `recipe.json`.

- Async calls are `Effect`s, async iterables are `Stream`s, and failures are tagged errors:
  `NodemailerError`.
- Handles it wraps: `Mail` (scoped, released by `close`).
- Services: `NodemailerMail`, each with a `layer`.
- `Upstream` re-exports nodemailer itself, and every facade keeps its upstream object as `.upstream`.

Offered: `createTransport`, `createTestAccount`. Types: bundled with the package.
