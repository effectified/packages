# @effectified/material-web

[@material/web](https://www.npmjs.com/package/@material/web) 2.5.0 for [Effect UI](https://ui.effect.website), generated by the [effectified engine](https://github.com/effectified/engine).

- 50 elements bound with `Html.customElement`: each property and event typed by @material/web's own declarations, each event's `detail` a message.
- Importing a binding (`@effectified/material-web/elements/AssistChip`) defines its element; `@effectified/material-web` defines them all.

```ts
import { AssistChip } from "@effectified/material-web";

// in a view: AssistChip(h).alwaysFocusable(...).on("update-focus", (detail) => Message.Changed({ ... }))
```

## Install

Released on GitHub, not npm. Effect UI is in public preview (install its snapshot build):

```sh
pnpm add https://github.com/effectified/packages/releases/download/material-web-v2.5.0/effectified-material-web-2.5.0.tgz effect https://pkg.pr.new/Effect-TS/ui/@effect/ui@2fd1a57
```

Types: bundled with the package.
