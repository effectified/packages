# @effectified/bullmq

[bullmq](https://www.npmjs.com/package/bullmq) 6.7.10 in [Effect](https://effect.website), generated by the [effectified engine](https://github.com/effectified/engine) from its types and `recipe.json`.

- Async calls are `Effect`s, async iterables are `Stream`s, and failures are tagged errors:
  `ConnectionClosedError`, `DelayedError`, `RateLimitError`, `RelayError`, `SchemaMigrationRequiredError`, `SchemaVersionMismatchError`, `UnrecoverableError`, `UnsupportedPostgresVersionError`, `WaitingChildrenError`, `WaitingError`, `BullmqError`.
- Handles it wraps: `QueueEvents` (scoped, released by `close`), `FlowProducer` (scoped, released by `close`), `Queue` (scoped, released by `close`), `Worker` (scoped, released by `close`), `Job`.
- Services: `BullmqQueueEvents`, `BullmqFlowProducer`, `BullmqQueue`, `BullmqWorker`, each with a `layer`.
- `Upstream` re-exports bullmq itself, and every facade keeps its upstream object as `.upstream`.

Offered: `QueueEvents`, `FlowProducer`, `Queue`, `Worker`. Types: bundled with the package.
